# Flashcards-app

## Stack
- Plain HTML, CSS and Javascript (no framework, no server, no build step)
- Data store in 'LocalStorage'

## Running the app
- Open 'index.html' directly in the browser

## Conventions
- One file per concern: 'index.html' , 'style.css' , 'app.js'
- Don't add external libraries or packages without asking me first
- If anything is unclear, ask me first

## Do not
- Add any npm dependencies
- commit any secrets
